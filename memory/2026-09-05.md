# 2026-09-05 — Sesión 3: Auditoría B2 y correcciones

## Resumen

Tercera sesión. Se realizó auditoría completa de las 11 migraciones SQL del B2 y se corrigieron 8 problemas de seguridad, concurrencia e integridad. Se creó la migración 00012 con funciones RPC atómicas.

## Trabajo realizado

### Auditoría de migraciones (00001–00011)

Problemas encontrados y corregidos:

1. **Enum `user_role` sin `customer`** — Agregado `customer` como primer valor del enum. Los clientes regulares no son staff.

2. **`profiles.role` default incorrecto** — Cambiado de `customer_service` a `customer`. Los nuevos registros no deben tener rol de staff.

3. **Race condition en `generate_order_number()`** — Agregado `pg_advisory_xact_lock(hashtext('order_sequence_' || v_year))` para evitar números duplicados bajo concurrencia.

4. **`update_stock_reserved()` sin validación** — Agregada verificación de que `stock - stock_reserved >= quantity` antes de crear reserva. Lanza `RAISE EXCEPTION` si no hay suficiente stock.

5. **Funciones SECURITY DEFINER sin `search_path`** — Todas las funciones ahora tienen `SET search_path = public, pg_temp` para prevenir ataques de inyección vía schemas maliciosos.

6. **`review_photos` solo admin** — Agregada política `review_photos_insert_own` para que clientes puedan subir fotos de sus propios reviews.

7. **`decrementStock()` race condition** — El servicio tenía un patrón read-then-write (leer stock, calcular, escribir). Reemplazado con RPC atómica `decrement_stock()` que usa `UPDATE ... WHERE stock >= quantity`.

8. **Sin RPC para reservas atómicas** — Creada `create_stock_reservation()` con `FOR UPDATE` lock para prevenir overselling.

### Nueva migración: 00012_add_stock_rpc_functions.sql

- `decrement_stock(p_product_id, p_variant_id, p_quantity, p_order_id, p_performed_by)` — Decremento atómico de stock
- `create_stock_reservation(p_product_id, p_variant_id, p_order_id, p_quantity, p_expires_at)` — Reserva atómica con lock
- `expire_overdue_reservations()` — Expiración masiva de reservas vencidas
