## Hallazgos de auditoría (todos corregidos)

1. `ProductBadge`: `{discount && discount > 0 && …}` renderizaba el literal
   "0" en TODAS las tarjetas (16/16) porque React pinta el número 0.
   → `{(discount ?? 0) > 0 && …}`
2. Portada "Destacados" vacía: ningún producto con `is_featured`.
   → Fallback a más recientes en `getFeaturedProducts` + `is_featured=true`
   a los 5 de Electrónica en Supabase.
3. Hero sin imágenes + botón "Saber más" muerto.
   → Collage con 3 fotos reales del catálogo (getNewProducts, enlazadas a
   ficha), fallback texto centrado; "Saber más" ancla a `#por-que-a2k`.
4. 6 categorías demo activas (tecnologia, audio, wearables, fotografia,
   accesorios, gaming) → filtros/footer/páginas vacías.
   → `is_active=false` en Supabase. Quedan 7 reales.
5. Admin "no puedo eliminar imagen": backend SANO (policies storage ALL
   admin, is_admin() OK, bucket OK, 0 huérfanas). El flujo era frágil:
   fallaba storage → no se borraba nada.
   → Ahora: borra registro BD primero, storage best-effort con `warning`,
   mensaje claro si la sesión no tiene permisos, URL null-safe.
